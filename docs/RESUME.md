# Résumé description

**Gaze + Mouth — Hands-free macOS interaction prototype**

Built a Python-based macOS prototype combining webcam gaze tracking, mouth gestures, visual speech recognition and CursorMix, a screen-aware AI assistant. Integrated macOS Accessibility, local and cloud models, and recorded-data evaluation to investigate hands-free navigation and desktop guidance.

**Short version:** Built a hands-free macOS prototype using gaze tracking, mouth gestures, visual speech and a screen-aware AI assistant.
