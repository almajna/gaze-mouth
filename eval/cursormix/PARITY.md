# CursorMix feature status

CursorMix is a research prototype for screen questions, pointing, guided workflows, and desktop assistance. It also includes optional dictation, annotations, a local history, and scheduled routines. See the [user guide](../../docs/USER_GUIDE.md#using-cursormix) for usage and requirements.

The recorded results support screen Q&A and pointing on the evaluated cases. Teaching and desktop action reliability require more live evidence, especially cancellation and verification across multiple applications. The build script produces a locally signed app. See the [evaluation report](results.md) for the measured results and limits.
